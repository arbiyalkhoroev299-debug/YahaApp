# Перенос стиля фото

Отдельное приложение (не связано со складом). Загружаете два фото — слева образец со стилем, справа своё фото — приложение переносит цветовую атмосферу образца на ваше фото.

## Как это работает
- Всё считается **прямо на телефоне**, без интернета и без отправки фото куда-либо.
- Приложение анализирует яркость, контраст и цветовой баланс обоих фото и "подгоняет" ваше фото под образец.
- Дополнительно показывает примерные значения для ручной донастройки в Snapseed (Тепло, Яркость, Контраст, Насыщенность).

## Честно об ограничениях
- Хорошо работает с общим тоном, светом и цветовой гаммой.
- Не скопирует точечные эффекты вроде зерна, виньетки или ручной перекраски отдельных объектов (например, только неба).
- Результат — приближение, а не математически точная копия стиля.
- Для скорости работы на телефоне фото обрабатываются с уменьшением до ~1100px по длинной стороне — для соцсетей более чем достаточно, для печати большого формата не подойдёт.

## Размещение на GitHub Pages
Точно так же, как складское приложение:

1. Создайте **новый отдельный репозиторий** на github.com, например `stil-foto` (Public).
2. Загрузите туда `index.html`, `manifest.json`, `sw.js` и папку `icons` (со всей структурой).
3. **Settings → Pages** → Source: **Deploy from a branch**, ветка **main**, папка **/ (root)** → Save.
4. Через минуту сайт будет доступен по ссылке `https://ваш-логин.github.io/stil-foto/`.
5. Откройте ссылку в **Safari** на iPhone → «Поделиться» → **«На экран Домой»**.

Это отдельный проект от складского приложения — они никак не связаны и не мешают друг другу.
